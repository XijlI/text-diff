# Text Diff — 面向长文段落的比对工具

一个单独的 HTML 文件：把两段文字**按词组 / 句子 / 字符**逐处比对，不切行。为正文类文本（文章、合同、邮件、译文、中英混排稿）准备——`git diff` 只能说"这一整段变了"，它不能。它也能直接读 `.docx`，两份 Word 稿不用打开 Word 就能比。

![红线视图](screenshots/redline-zh.png)

双击 `TextDiff.html` 即可。不用安装、不起服务、不联网，复制到任何地方都能用。

## 能做什么

- 左右两栏粘贴，或把文件拖进任一栏，或点「载入文件」——支持 `.txt` `.md` `.csv` `.json` 和 **`.docx`**。边打字边重算。
- **两栏中间的 ⇄**：一键互换原文和新文（右上角的「交换左右」同效）。
- **界面中英双语**：`EN` / `中文` 一键切换，会记住选择；首次打开跟随浏览器语言。
- **主题**：右上角的太阳 / 月亮图标切换浅色与深色，首次打开跟随系统。
- **三档粒度**
  - 词组 — 英文按词切、**中文按字切**，所以改一个字就标一个字，而不是整段变红。
  - 句子 — 以句子为单位，适合看哪几句被重写。
  - 字符 — 逐字符，查错别字、编号、版本号。
- **三种视图**
  - 红线 — 单栏连续排版，删除用红色删除线、新增用绿色下划线，段落仍是段落。
  - 并排 — 左右两栏各自流动，只高亮改动，滚动联动。
  - 改动清单 — 每处改动编号并带上下文，点「定位」直接跳到那一处。
- **开关**：忽略换行与空白（默认开——重新排版不算改动）、忽略大小写、忽略标点、删除线。
- 统计：两侧字数、新增/删除字数、相似度，`‹ ›` 逐处跳转。
- 复制红线得到 `[-旧-]{+新+}`；复制 Markdown 得到 `~~旧~~` / `==新==`（可直接粘进 Obsidian）。
- **导出 Word 修订稿**：把比对结果写成真正的 `.docx` 修订（`w:ins` / `w:del`，作者 "Text Diff"），用 Word 打开就是「审阅 → 所有标记」，对方可以逐处接受或拒绝。整个 docx 在页面里现场拼出来（自己写 ZIP + `word/document.xml`），不上传任何东西。
- 上次的文本和设置会从本地存储恢复；点「清空」可一并清掉。

## .docx 是怎么读的

`.docx` 本质是一个装满 XML 的 ZIP。工具通过 ZIP 中央目录找到 `word/document.xml`，用浏览器自带的 `DecompressionStream` 解压，再从 WordprocessingML 里取正文：段落、手动换行、制表符、表格（一行一行读，单元格之间用 Tab）、内容控件里的文字。格式一律丢掉——只比文字。`w:del`（修订里的删除）会被跳过，所以带未接受修订的稿子按"接受后"的状态读。

## 导出 Word 修订稿

「导出 Word 修订稿」是在页面里现场拼出文件的：自己写 ZIP（stored 存储 + CRC32）加三个部件——`[Content_Types].xml`、`_rels/.rels`、`word/document.xml`；删除的文字放在 `<w:del><w:r><w:delText>` 里，新增的放在 `<w:ins><w:r><w:t>` 里，都带作者和时间。Word 打开后就是普通文档的修订状态，「审阅 → 所有标记」能看到痕迹，「接受所有修订」就变回新版本。

两点如实说明：段落**标记**不参与修订（删掉一个换行不会显示为被删除的段落标记），导出的文件也只带 A4 页面和 1.15 倍行距这两项基础排版。

## 已知边界

- `.pdf` 和旧版 `.doc` 会明确拒绝并提示（`.doc` 请先另存为 `.docx`；PDF 请复制正文）。
- 格式、批注、脚注、页眉页脚、图片不参与比对。
- 两份**毫不相关**的长文，任何 diff 算法都很贵；超过一万字时本工具会放弃逐词对齐、整块标为替换并提示「差异过大，已按整块比较」，而不是卡死。
- 保存用的是浏览器本地存储，跟着这台机器这个浏览器走，不同步到别处。

## 重新构建

`TextDiff.html` 是生成出来的：`build.py` 把 `src/diff.min.js`（jsdiff 5.2.0，MIT）内联进 `src/app.html`。

```
python3 build.py     # 重新生成 TextDiff.html
```

想改功能就留好 `src/` 和 `build.py`；日常使用只需那个 HTML，单独拷走也能跑。
